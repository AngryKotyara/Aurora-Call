# Aurora Call

Браузерное приложение для аудио- и видеозвонков между друзьями с демонстрацией экрана. Клиент использует WebRTC для медиапотоков и Supabase RPC для регистрации, списка друзей и обмена сигналами.

Исходный одностраничный клиент восстановлен из production-развёртывания Vercel `aurora-call` и разделён на независимые модули без смены технологии или пользовательского сценария.

## Структура

| Путь                       | Назначение                                     |
| -------------------------- | ---------------------------------------------- |
| `index.html`               | HTML-оболочка приложения                       |
| `src/app.js`               | Инициализация, авторизация, друзья и история   |
| `src/api.js`               | Клиент Supabase RPC                            |
| `src/calls.js`             | WebRTC и обработка сигналов звонка             |
| `src/state.js`             | Состояние приложения и локальная сессия        |
| `src/ui.js`                | Шаблоны и обработчики интерфейса               |
| `src/media-permissions.js` | Доступ к камере и микрофону и его статус       |
| `src/utils.js`             | Экранирование, хеширование и служебные функции |
| `src/config.js`            | Публичная клиентская конфигурация              |
| `src/styles.css`           | Стили                                          |
| `test/`                    | Тесты независимых утилит                       |

## Развёртывание

Проект собирается Vite в каталог `dist` и может быть импортирован в Vercel без дополнительной конфигурации.

Разрешение на камеру и микрофон запрашивается только после явного нажатия пользователя. Браузер хранит его для домена, а Aurora Call дополнительно сохраняет успешный статус отдельно для аккаунта на текущем устройстве. Разрешение не переносится на другой браузер или устройство и может быть отозвано пользователем в настройках сайта.

Во время видеозвонка отдельная кнопка заменяет исходящий видеотрек на захват экрана. Микрофон продолжает работать, а после системной остановки демонстрации приложение автоматически возвращает изображение с камеры.

## Backend

Клиент ожидает следующие Supabase RPC-функции:

- `register_call_user`
- `login_call_user`
- `list_call_friends`
- `list_call_history`
- `create_call_friend_code`
- `accept_call_friend_code`
- `remove_call_friend`
- `send_call_signal`
- `poll_call_signals`
- `record_call_event`

Актуальные изменения RPC хранятся в `supabase/migrations`. Базовая SQL-схема исходного приложения не входила в Vercel deployment. Значение `supabasePublishableKey` является публичным браузерным ключом; service-role ключи и другие секреты в репозитории отсутствуют.
