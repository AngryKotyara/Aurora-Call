# Aurora Call

Браузерное приложение для аудио- и видеозвонков между друзьями. Клиент использует WebRTC для медиапотоков и Supabase RPC для регистрации, списка друзей и обмена сигналами.

Исходный одностраничный клиент восстановлен из production-развёртывания Vercel `aurora-call` и разделён на независимые модули без смены технологии или пользовательского сценария.

## Структура

| Путь             | Назначение                                       |
| ---------------- | ------------------------------------------------ |
| `index.html`     | HTML-оболочка приложения                         |
| `src/app.js`     | Инициализация, авторизация, друзья и приглашения |
| `src/api.js`     | Клиент Supabase RPC                              |
| `src/calls.js`   | WebRTC и обработка сигналов звонка               |
| `src/state.js`   | Состояние приложения и локальная сессия          |
| `src/ui.js`      | Шаблоны и обработчики интерфейса                 |
| `src/utils.js`   | Экранирование, хеширование и служебные функции   |
| `src/config.js`  | Публичная клиентская конфигурация                |
| `src/styles.css` | Стили                                            |
| `test/`          | Тесты независимых утилит                         |

## Локальный запуск

```bash
npm run dev
```

```bash

npm run format:check

```

## Развёртывание

Проект собирается Vite в каталог `dist` и может быть импортирован в Vercel без дополнительной конфигурации.

## Backend

Клиент ожидает следующие Supabase RPC-функции:

- `register_call_user`
- `login_call_user`
- `list_call_friends`
- `create_call_friend_code`
- `accept_call_friend_code`
- `send_call_signal`
- `poll_call_signals`
- `record_call_event`

SQL-схема и код этих функций не входят в Vercel deployment и поэтому не могут быть восстановлены из фронтенда. Значение `supabasePublishableKey` является публичным браузерным ключом; service-role ключи и другие секреты в репозитории отсутствуют.
